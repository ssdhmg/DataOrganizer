# DataOrganizer — 测试数据自动整理工具

把温循/漂移测试导出的原始 CSV，按 Excel 模板批量整理成带图表、带寄存器截图、标题与测试时间自动更新的报告文件。

日常用法：选好原始数据（可多选）→ 选模板 → 选寄存器截图 → 选输出文件夹，程序自动跑完。

---

## 下载 / 使用

👉 **[Releases 页面下载 `DataOrganizerv2.3.exe`](../../releases)** ，双击即用，无需安装 Python。

### 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7 SP1（64 位）及以上 |
| Excel | 需安装 Microsoft Excel（程序通过 COM 调用 Excel 生成图表） |
| VC 运行库 | Visual C++ 2015-2022 Redistributable x64 |

> 若启动报错提示缺少 `VCRUNTIME140.dll`，安装 [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) 即可。装了 Office 的机器通常已自带。

## 界面

| 控件 | 说明 |
|---|---|
| 选择原始数据（可多选） | 一次性选中多个 CSV，按通道依次处理 |
| 选择模板文件 | 含 8 个图表的 `.xlsx` 模板 |
| 选择寄存器截图文件 | 图片按从左到右排列，对应通道 0、1、2、3 |
| 文件名后缀 | 追加到输出文件名末尾，默认 `(-40_125)` |
| 迁移数据行数 | 从每个 CSV 取前 N 行数据，默认 80 |
| 选择输出文件夹并开始 | 选完即开始，日志实时显示在下方面板 |

输出文件名格式：`{CSV文件名}_{ID}_{后缀}.xlsx`

## v2.3 更新内容

### 1. 大幅提速（老机器上实测 77 倍）

原版本在 Win7 老硬件上处理 4 个文件要 70 秒以上，主要瓶颈是每个 CSV 都重新打开一次模板（模板含 8 个图表 + 文本框，Excel 每次都要完整解析）。

| 项目 | v2.2 及以前 | v2.3 |
|---|---|---|
| Excel 进程 | 每个文件启停一次 | **全程只启动一次**，最后统一退出 |
| 模板加载 | 每个 CSV `Workbooks.Open` 一次 | **只打开一次作母版**，之后 `Worksheets.Copy()` 复制副本 |
| 写数据 | 逐单元格赋值（5000+ 次 COM 往返） | **二维数组一次赋值**，单次往返 |
| 图表校验 | 先落盘再用 openpyxl 重开文件读 | 直接读内存中图表的 `Series.Formula` |
| 关停选项 | 仅 `Visible`/`DisplayAlerts` | 增加 `EnableEvents`、`ScreenUpdating`、`AskToUpdateLinks` |

实测：**74.6 秒 → 0.97 秒**（不含 Excel 冷启动）。

### 2. 电流校验功能重写（原先实际未生效）

按需求校验**处理好的数据中不同百分点的电流值**与**模板图表坐标（系列名）的设定电流**，偏差超过 **10% 只警告、不中断**，后续步骤照常执行。

实现方式是解析每个图表系列的 `SERIES(...)` 公式，用 Y 值（Offset）所在列向左定位最近的 `xx% Current` 列，取该列**前 5 行**平均值与系列名中的设定电流比对。第一个 Offset 列属 Vref 参考块，自动跳过；同一张图同一列只报一次，不刷屏。

典型日志：

```
图表8 校验通过：列 S 平均 10.0402A vs 设定 10A，偏差 0.40%
警告：图表6 列 AT 前 5 行平均电流 40.0614A，与设定值 80A 偏差 49.92% > 10%，请检查数据
电流校验完成：共校验 11 组图表数据，其中 4 组偏差超过 10%，已按警告处理，流程继续
```

### 3. 修复的两个数据错误 Bug

- **测试时间被写坏**：原正则 `(测试时间[:：]\s*)[^\r\n]*` 的 `\s*` 会跨行吞掉后续内容，实际输出变成了 `P26.10.12`，且"测试人员/地点/样品/项目/设备"整段丢失。改为按日期格式 `\d{4}[.\-/]\d{1,2}[.\-/]\d{1,2}` 精准替换。
- **温度列误报**：`check_temperature_column` 用 `ws.max_row`（模板自带 81 行），数据不足时会把模板残留算进去。改为传入真实 `last_row`，并兼容纯数字单元格。

## 打包说明

仓库内 `DataOrganizer.spec` 是针对 Win7 的打包配置：

- 构建环境 **Python 3.7.6 + PyInstaller 5.13.2**（Python 官方从 3.9 起放弃 Win7，3.7 是最后一个受支持版本）
- 输出 x64 单文件、GUI 无控制台
- 关闭 UPX（老硬件解压慢、部分杀软误报）
- 剔除 numpy / pandas / matplotlib / PyQt5 等无关依赖

重新打包：

```bash
py -3.7 -m PyInstaller --noconfirm --clean DataOrganizer.spec
```
